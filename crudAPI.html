The Crud-API

In this backend-heavy individual project, the task was to create an API which provides CRUD-operations for a webshop.

Role: Fullstack developer

Concept and Results

The task was to implement CRUD-operations in a webshop application. The frontend was kept minimal, serving only to demonstrate the backend functionality. I used Express to create a router that handles CRUD operations (Create, Read, Update, Delete) on data stored in a MongoDB database. The API was designed with a nested data structure, consisting of products and their corresponding quantities. The router uses URL routes to call controller functions, which in turn uses the mongoose-model from the database to perform CRUD-operations. The browser will take a while to update the products on the website (ca 1 min the first time) .
