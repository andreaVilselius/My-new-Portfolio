Concept

The task

The task was to implement CRUD operations (Create, Read, Update, Delete) in a webshop application. The frontend was kept minimal, serving only to demonstrate the backend functionality.

The API uses a nested data structure, consisting of products and their corresponding quantities.

02

How it works

From request to database

An Express router maps each URL route to a controller function. The controller uses a Mongoose model to read from and write to MongoDB.
