Concept

Azeea is aspiring to create a mobile application that works pretty much like Tinder - but for events. My role in the project was to design examples of the main flow and frames for when the user swipes right on an event - using Figma & SwiftUI. Once the user has entered an Event they can access the event-page, which could for example be a art meetup or a consert. The user can also have multiple avatars, representing different interests. Below is a storyboard illustrating the user flow of a typical user.

02

My Role

Designed and implemented UI screens in Figma and SwiftUI for a mobile event app. Contributed from concept to delivery, working closely with developers and testers and other designers. Focused on intuitive navigation and a clean, modern look. Contributed to shaping the brand’s identity by designing cohesive visual elements, including icons, typography, and color schemes, aligned with the company’s values.
